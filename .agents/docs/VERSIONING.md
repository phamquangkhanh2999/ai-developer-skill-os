# Versioning Policy — AI Developer Skill OS V10

## Semantic Versioning: `MAJOR.MINOR.PATCH`

Current: `10.2.0`

### Bản đồ Kiến trúc các Phiên bản

| Version | Identity                  | Architecture                               |
| ------- | ------------------------- | ------------------------------------------ |
| V7      | Prompt Collection         | Static instructions                        |
| V8.x    | Skill System              | Structured capabilities                    |
| V9.x    | Governed Capability Graph | Decision boundaries + lifecycle governance |
| V10.x   | 11 Super-Skills           | V10.2 — Confidence Model, Exit Codes, Evidence Format, Compliance |

---

## When to bump each segment

### MAJOR (10.x.x → 11.0.0)
Breaking changes that require skill/workflow authors to update their files.

### MINOR (10.2.0 → 10.3.0)
Backward-compatible additions.

```
✅ Examples:
- Adding a new skill
- Adding a new workflow
- Adding a new reference file
- Adding a new rule to rules/
```

**Gate:** No migration required. Existing skills remain valid.

### PATCH (10.2.0 → 10.2.1)
Fixes that don't change behavior.

## V10.2 Migration Notes

All skill files, rule files, and workflow files MUST have version `10.2.0` in frontmatter.

### New Required Sections in Every SKILL.md:
- `## Mô Hình Độ Tin Cậy (Confidence Model)`
- `## Thoái Ra Mã (Exit Codes)`
- `## Bằng Chứng Định Dạng (Evidence Format)`
- `## Compliance`

### Registry Files:
- `graph.json` and `index.yaml` — generated by `node tooling/build-registry.js`
- Old files (`capability-graph.yml`, `skills-index.yml`) — REMOVED in V10

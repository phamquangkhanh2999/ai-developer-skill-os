# Release 10.3.0 — Controlled Subagent Orchestration

## Behavior và compatibility

Giữ 11 skills và routing hiện tại. Review và điều tra bug có thể chạy tối đa hai child chỉ đọc, depth một, khi runtime Antigravity có capability/quyền phù hợp và công việc độc lập. Task nhỏ hoặc tool thiếu chạy single-agent. Claude/OpenCode dùng fallback này trong release hiện tại.

Feature mặc định single-agent. Parallel-write chỉ dùng khi user opt-in và pilot thực tế đã được kiểm chứng: chốt contract, một writer/file, lead giữ shared files và integrate trước kiểm thử cuối. Role label không tự giới hạn quyền; policy không thay thế sandbox/runtime enforcement.

## Cài đặt và upgrade

Yêu cầu Node.js >=18. Chạy lệnh từ dự án đích, không chạy local install vào chính checkout source package:

```bash
# Chỉ dự án hiện tại
npx ai-developer-skill-os@10.3.0 --ide=antigravity --scope=local --force

# Tất cả dự án trên máy
npx ai-developer-skill-os@10.3.0 --ide=antigravity --scope=global --force
```

Installer backup thư mục cấu hình đích trước overlay, giữ DEV_PROFILE.md đã có và custom agents ngoài managed paths. GEMINI.md cũ được backup riêng. Managed skills/rules/workflows bị cập nhật; đối chiếu backup nếu đã chỉnh các file này. Cùng version không ghi lại nếu thiếu --force.

Package 10.3.0 không buộc tất cả components cùng version. Ba skills/workflows review, feature, bug lên 10.3.0; components không đổi giữ 10.2.0. Không chạy legacy sync:v10 vì script hardcode 10.2.0 và ghi rộng.

## Smoke checks sau upgrade

1. Xác nhận version marker dòng đầu là 10.3.0 và GEMINI.md có Section 6 mới.
2. Mở policy rules/subagent-orchestration.md và ba skill/workflow đã nâng cấp.
3. Kiểm tra profile/custom agents còn nguyên; chạy prompt config nhỏ để xác nhận single-agent.
4. Thử module review chỉ đọc, xác nhận actual mode, evidence và cleanup.
5. Chỉ thử multiple writers trên fixture riêng sau contract/ownership; giữ opt-in cho đến khi có final integration evidence.

## Rollback

Lấy đường dẫn backup mà installer in ra. Khôi phục các file managed cần thiết và GEMINI.md từ backup tương ứng; xem diff để giữ thay đổi user sau upgrade. Nếu cần quay lại package 10.2.0, installer bản đó có thể xóa thư mục đích, nên backup độc lập trước khi sử dụng. Không xóa toàn bộ customization để rollback.
